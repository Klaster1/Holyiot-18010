# Reference documents

The PDFs in this folder are downloaded copies and stay out of git. The links below are the sources.

| Document | Source | Local copy |
| --- | --- | --- |
| Holyiot-18010 datasheet, version 1, 2018-01-01. Page 6 has the mechanical drawing, pages 7-8 the pinout. | [holyiot.com](http://www.holyiot.com/tp/2019042516322180424.pdf) | `Holyiot-18010-nRF52840-datasheet.pdf` |
| Product listing with photos, used for pad, shield and antenna sizes | [AliExpress item 32951888809](https://www.aliexpress.com/item/32951888809.html) | none |

To fetch the datasheet:

```sh
curl -o docs/Holyiot-18010-nRF52840-datasheet.pdf http://www.holyiot.com/tp/2019042516322180424.pdf
```
